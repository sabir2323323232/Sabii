Mukammal Guide — Har Game Kaise Khelna Hai

1. Sequence Lazmi Hai (1 → 2 → 3): Jab user khel raha ho toh woh direct agle game par nahi ja sakta. Pehle 1st game sahi chuno aur Submit karo, tab 2nd game khulega, aur uske baad 3rd game khulega.

2. Pehla Game (Word Unscramble): Bikhre hue letters se sahi English word chuno (is ke liye maths aana zaroori nahi). Sahi jawab select kar ke Submit dabayein.

3. Dosra Game (Odd One Out): Jo word baqi group se alag ho us par tap karo aur Submit dabayein.

4. Tesra Game (Mushkil Reverse / Pattern Match): Yeh 3rd game thoda mushkil hota hai — ulta/pattern word dhyan se chuno aur Submit dabayein.

5. Haarne Par Try Again: Agar kisi bhi game mein ek baar bhi haare toh ghalat jawab count hoga aur user ko Try Again dabana hoga — Try Again par direct ad chalega aur user ko dobara sahi khel kar aage barhna hoga.

6. Har 5 Games Par 5 Ads & Daily Limit: Har 5 games jeetne ke baad (5, 10, 15, 20...) 5 ads aayenge jin par 10-10 seconds rukna hoga. Din mein 50 games ke baad 24 hours ka lock lagega.

Brain Game Tafseeli Guide

Step-by-Step Khelne Ka Tariqa: Aap seedha agle game par jump nahi kar sakte. Pehle 1st game solve kar ke Submit karein, phir 2nd game, aur phir 3rd game khulega.

1st Game (Word Unscramble): Letters ko jor kar sahi word select karein (maths ki koi zaroorat nahi).

2nd Game (Odd One Out): Jo cheez/word baqi se alag ho usay select karein.

3rd Game (Mushkil Challenge): Yeh 3rd game mushkil hota hai — ulta/pattern word dhyan se chunein.

Haar & Try Again: Agar ek baar bhi haare toh Try Again dabayein; Try Again par direct ad open hoga aur dobara khelna hoga.

Har 5 Games Par 5 Ads: 5, 10, 15, 20... har 5 games ke baad 5 ads (10s each) poore karne honge. Din mein 50 games ke baad 24h lock lagta hai.
